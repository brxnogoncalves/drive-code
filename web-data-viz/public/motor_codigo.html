Como carros me ensinaram tecnologia

A curiosidade por motores, módulos eletrônicos e funcionamento dos carros acabou se transformando em interesse por programação, dados e sistemas embarcados.

O que é rede CAN?

A rede CAN é uma comunicação usada nos veículos para que os módulos eletrônicos troquem informações entre si, como sensores, botões, rotação, velocidade e comandos. Ela mostra como um carro moderno também é feito de dados e tecnologia.

Projetos que desenvolvi

Desenvolvi projetos envolvendo firmware, leitura de mensagens CAN, simulações. Esses projetos me ajudaram a entender como programação pode sair da tela e interagir com o mundo real.

Keep Start

Projeto de firmware automotivo desenvolvido para desativar automaticamente o sistema Start/Stop de veículos. Utiliza leitura de mensagens da rede CAN, lógica embarcada e comunicação entre módulos para identificar o estado do carro e executar comandos automaticamente.

BPower Pedal

Módulo automotivo criado para melhorar a resposta do acelerador eletrônico, reduzindo atrasos na aceleração e proporcionando uma sensação de maior desempenho ao dirigir. O projeto utiliza firmware embarcado e integração eletrônica com o sistema do pedal.

Fiat/Stellantis/Mopar Dash Pulse Abarth

Projeto automotivo desenvolvido para leitura de informações do veículo através de requisições OBD utilizando PIDs padrões da norma automotiva. O módulo realiza consultas em tempo real para obter dados como rotação, velocidade, temperatura e outros parâmetros do carro, exibindo essas informações em uma interface dedicada.
